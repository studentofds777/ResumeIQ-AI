# ResumeIQ AI

## Overview
ResumeIQ AI is an AI-powered web application that helps job seekers improve their resumes. It analyzes resumes, calculates an ATS score, generates professional summaries, builds resumes, and provides interview preparation tools.

## Features

- AI Resume Analyzer
- ATS Compatibility Score
- AI Resume Builder
- Professional Summary Generator
- Resume PDF Download
- Interview Preparation
- Resume History
- Modern User Interface
- Responsive Design

## Technologies Used

- Google AI Studio
- HTML
- CSS
- JavaScript
- AI APIs
- GitHub
- Vercel

## How to Use

1. Open the application.
2. Enter your personal information.
3. Add education, experience, skills, and projects.
4. Generate an AI summary.
5. Analyze your resume.
6. Review the ATS score.
7. Download the resume as a PDF.
