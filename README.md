# ResumeIQ AI

## AI-Powered Resume Analyzer and Resume Builder

## Project Overview

ResumeIQ AI is an intelligent web application that helps job seekers create professional resumes, analyze existing resumes, improve ATS compatibility, generate AI-powered professional summaries, and prepare for interviews.

The application uses Google's Gemini AI to provide personalized suggestions, resume analysis, and career guidance through a simple and modern interface.

---

## Problem Statement

Many job seekers struggle to create ATS-friendly resumes and receive little feedback about their resume quality. ResumeIQ AI solves this problem by providing AI-powered analysis, resume building, and interview preparation in one platform.

---

## Objectives

- Build ATS-friendly resumes.
- Analyze uploaded resumes.
- Generate AI professional summaries.
- Help users prepare for interviews.
- Improve resume quality using AI.

## AI Features

The application uses Google's Gemini AI to:

- Analyze resumes
- Generate ATS feedback
- Suggest resume improvements
- Generate professional summaries
- Create interview questions
- Provide career recommendations

---

## Application Workflow

1. User signs in using Google.
2. User uploads an existing resume or creates a new one.
3. Gemini AI analyzes the resume.
4. ATS score is generated.
5. AI suggests improvements.
6. User edits the resume.
7. Resume is downloaded as PDF.
8. User prepares for interviews using AI-generated questions.
